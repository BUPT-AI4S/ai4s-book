# 公开教材官网设计

已确认：在 BUPT-AI4S 下建立小写命名的 `ai4s-book` 公开项目，通过 GitHub Pages 免费网址发布。现有私有书稿继续用于 Overleaf 编写。公开首版的三章网页正文、PDF、配图和引用，LaTeX 源码与内部导入资料不进入公开仓库。

首页介绍《科学智能原理与实践》、作者鄂海红与徐坤、目标读者和内容主线。正文以当前 main.tex 的三章及顺序为准，不继续使用旧的22章规划。首页提供在线阅读、完整PDF、章节PDF、配套课程、GitHub Star和纠错入口。采用北邮蓝、纸张色背景、清晰中文正文，保持与书稿一致的封面。无装饰绿点、假排名或虚构推荐语。

README 参考 Happy-LLM 的居中标题、真实徽章、中文/English、阅读入口及完整目录。英文 README 是项目介绍的翻译，中文书稿不会自动翻译。公开阅读与内容版权范围明确说明，不擅自选用未获团队确认的宽泛开放许可。

使用本地生成工具，从私有仓库显式同步到忽略的 `.textbook-source/`。Pandoc 输出HTML/MathML；自定义小贴士、图表、脚注与交叉引用保留。完整LaTeX书稿编译一次，按PDF书签拆分三章，附完整共享参考文献以保持原引用编号。公开成品含源码摘要及文件校验和。CI只校验、暂存成品，不读取私有仓库。

阅读页提供网页正文与PDF原版模式、目录、前后章导航和下载；本地PDF.js负责显示PDF。发布使用相对URL，兼容 `/ai4s-book/` 项目路径。独立域名和收费服务器不在本次范围。

验收：三章顺序正确，32幅图和2张正文表格完整，章节/图/表引用无悬空，完整PDF与分章PDF可读；320px到桌面布局、深浅主题和中英导航可用；公开文件无私有书稿、凭据、内部导入记录。创建公开仓库和Pages仅在本地成品验证后执行。

# 公开教材官网设计

项目位于 `BUPT-AI4S/ai4s-book`，通过 GitHub Pages 发布，提供三章网页正文、配图和参考文献。

首页介绍《科学智能原理与实践》、作者鄂海红与徐坤、目标读者和内容主线，提供在线阅读、配套课程、GitHub Star 和授权联系入口。英文标题为 AI FOR SCIENCE: PRINCIPLES AND PRACTICE。采用北邮蓝、纸张色背景与清晰的中文排版。

README 提供居中标题、项目徽章、中英文介绍、阅读入口、章节目录、贡献指南和引用信息。

使用本地生成工具，从选定版本同步到 `.textbook-source/`。Pandoc 输出 HTML/MathML，保留小贴士、图表、脚注与交叉引用。阅读版统一省略工程说明。成品记录来源摘要及文件校验和，CI 校验并发布网页，不发布 PDF。

阅读页提供网页正文、PDF 原版预览、目录和前后章导航。预览使用原版 PDF 转换的页面图像，支持翻页、跳页、缩放；公开文件不包含 PDF，也不提供下载按钮。旧 PDF 阅读页链接跳转至对应章节的预览模式。发布使用相对 URL，兼容 `/ai4s-book/` 项目路径。

验收：三章顺序正确，32 幅图和 2 张表格完整，章节、图表引用有效；320px 到桌面布局、深浅主题和中英导航可用；课程链接和授权邮箱正确，发布文件不包含 PDF。

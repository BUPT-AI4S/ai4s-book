# 公开教材官网设计

项目位于 `BUPT-AI4S/ai4s-book`，通过 GitHub Pages 发布，提供三章网页正文、PDF、配图和参考文献。

首页介绍《科学智能原理与实践》、作者鄂海红与徐坤、目标读者和内容主线，提供在线阅读、完整 PDF、章节 PDF、配套课程、GitHub Star 和反馈入口。采用北邮蓝、纸张色背景与清晰的中文排版，封面与教材 PDF 一致。

README 提供居中标题、项目徽章、中英文介绍、阅读入口、章节目录、贡献指南和引用信息。

使用本地生成工具，从选定版本同步到 `.textbook-source/`。Pandoc 输出 HTML/MathML，保留小贴士、图表、脚注与交叉引用。阅读版统一省略工程说明，完整教材编译后按 PDF 书签拆分三章，附共享参考文献以保持原引用编号。成品记录来源摘要及文件校验和，CI 校验并发布成品。

阅读页提供网页正文与PDF原版模式、目录、前后章导航和下载；本地PDF.js负责显示PDF。发布使用相对URL，兼容 `/ai4s-book/` 项目路径。独立域名和收费服务器不在本次范围。

验收：三章顺序正确，32 幅图和 2 张表格完整，章节、图表引用有效，完整与分章 PDF 可读；320px 到桌面布局、深浅主题和中英导航可用。

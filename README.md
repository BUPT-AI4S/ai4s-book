## 关于本书

科学智能不仅需要选择模型，也需要说明科学问题如何表达、知识如何组织、实验结果怎样反馈，以及什么样的评价能够支撑结论。《科学智能原理与实践》围绕这些问题，连接科学研究中的知识、行动与评价。

本书围绕**科学数据、科学知识建模、基础模型预训练、科学智能体、可信测评与自主实验室**六个主题展开，结合研究案例、64 幅配图、13 张表格及参考文献，系统介绍从数据基础到科研闭环的方法与实践。

## 你将学习什么

- 区分结构化记录、本体和知识图谱的分工，理解科学知识怎样进入检索、推理与候选设计。
- 理解计算决策、实验执行和测量反馈如何组成闭环，比较不同领域的指标、约束与停止条件。
- 区分科学任务、研究工作流与科学发现的评价目标，审查测试数据、评分方法和结论的适用边界。

## 如何阅读

<strong>适合读者：</strong>理工科高年级本科生、研究生，以及希望开展科学智能研究的跨学科研究人员。

<strong>建议基础：</strong>基础数学与统计、机器学习概念，以及基本 Python 阅读能力。具体先修知识见各章学习目标。

- 第 1—3 章：从科学数据、知识组织到基础模型，建立方法基础。
- 第 4—6 章：通过科学智能体、可信测评与自主实验室，理解科研任务与实验闭环。

网站提供适合手机、平板和电脑屏幕的网页正文，以及保留原版排版的 PDF 预览。预览支持连续滚动、翻页、页码跳转、缩放和引用跳转，可在查看参考文献后返回原引用位置。教材正文为中文，项目介绍与网站导航提供中英文切换。

## 关于本书

科学智能不仅需要选择模型，也需要说明科学问题如何表达、知识如何组织、实验结果怎样反馈，以及什么样的评价能够支撑结论。《科学智能原理与实践》围绕这些问题，连接科学研究中的知识、行动与评价。

当前公开版本包含三章已有正文：**科学知识建模与大模型推理、自主实验室与干湿闭环、科学智能的测评数据构建与可信评价**。章节包含案例、32 幅原稿配图、2 张文字表格及参考文献，内容将随编写与审校持续修订。

> 本项目为协作编写稿，尚非正式出版定稿。原稿研究年份、数值与结论按正文保留，具体适用条件和来源说明见各章；公开发布不代表已独立核验所引研究的全部科学结论。

## 你将学习什么

- 区分结构化记录、本体和知识图谱的分工，理解科学知识怎样进入检索、推理与候选设计。
- 理解计算决策、实验执行和测量反馈如何组成闭环，比较不同领域的指标、约束与停止条件。
- 区分科学任务、研究工作流与科学发现的评价目标，审查测试数据、评分方法和结论的适用边界。

## 如何阅读

**适合读者：**理工科高年级本科生、研究生，以及希望开展科学智能研究的跨学科研究人员。

**建议基础：**基础数学与统计、机器学习概念，以及基本 Python 阅读能力。具体先修知识见各章学习目标。

- 关注知识组织与推理，从第 1 章开始。
- 关注实验执行与反馈，从第 2 章开始。
- 关注测评数据与结论可信度，从第 3 章开始。

网站提供适合不同屏幕的**网页正文**与保留 LaTeX 排版的 **PDF 原版**两种阅读方式。书稿正文为中文；English README 和英文界面用于项目介绍与导航，不代表正文已有英文译本。
